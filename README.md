# HoneyKat11.github.io

The personal portfolio of Katarya Johnson-Williams, built with React and Vite and hosted on GitHub Pages.

## Local development

Use a current Node.js release supported by the installed Vite version.

```powershell
npm ci
npm run dev
```

Vite prints the local URL after the development server starts.

## Validation

```powershell
npm test
npm run build
npm run preview
```

## Editing content

Update professional copy and public links in `src/data/siteContent.js`. Page structure lives in `src/App.jsx`, while the visual system lives in `src/index.css` and `src/App.css`.

The initial copy intentionally avoids employer details, resume claims, private contact information, and links that have not been confirmed.
